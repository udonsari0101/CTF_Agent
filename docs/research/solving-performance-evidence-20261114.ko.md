# 2026-11-14 풀이 경로 검증과 평가 결정

## 확인한 범위

v0.4.75 (`39fbf10d4288b82550b7f7d9bf461a193ad3e4ad`)를 운영 서비스에 배포했다. 문제 본문에 제시된 분석 도구 URL을 풀이 대상 원격 주소로 저장하던 결함은 `ctf_agent/ctfd.py`에서 수정했다. CTFd 본문 감지와 수동 등록 회귀 검사를 통과했고, 배포 후 실제 서비스에서 같은 본문으로 문제를 새로 만들어도 원격 주소가 생기지 않았다. 새 문제는 확인 후 삭제했다.

다음 수치는 공개 가능한 *단일 실행 관측값*이다. 입력과 독립 정답 해시는 비공개로 보관했고, 정답 문자열·로그·인증 정보는 저장소에 넣지 않았다. `완료`와 독립 정답 해시 일치가 함께 확인된 실행만 적었다.

Crypto 두 번은 같은 문제 본문·암호문, 계정, 모델(`gpt-6-sol`), 추론, 네트워크 정책과 CLI 바이너리 해시를 사용했다. 다만 실행 순서가 고정됐고 이미지와 문제 이름이 달라, 11.1초 차이를 하네스의 인과적 개선으로 해석할 수 없다. 다른 세 분야는 짝지은 대조군이 없으므로 분야별 성공 여부만 보여준다. 공개 풀이 검색이 섞일 가능성도 별도 통제되지 않았다.

서비스 job API에는 최신 응답의 컨텍스트 사용량이 있지만, 시도 전체의 입력·출력 토큰과 과금액은 없다. 따라서 이 다섯 실행의 토큰·비용은 `unknown`이다. 컨텍스트 창 사용률을 비용으로 환산하지 않는다. 기존 96회 정적 시험은 중단 상태이며, 서로 다른 시험의 부분 결과를 합쳐 순위를 매기지 않는다.

## 이번 결정

- v0.4.75의 원격 주소 결함 수정은 기능 회귀와 실제 풀이 경로로 검증했다. 기본 모델·추론 수준·프롬프트·worker 수는 이 예비 수치만으로 바꾸지 않는다.
- 사용자가 반복 대형 벤치마크를 줄이고 결함 수정에 집중하도록 범위를 바꿨으므로, 중단된 96회 시험은 재개하지 않는다. B0/B1/C1의 통제된 AB/BA 반복과 보류셋 평가는 **미실행**이며 성능 우위도 **미확인**이다.
- 이후 기본값 변경이 필요할 때는 기존 [평가 프로토콜](../benchmarking/protocol.md)의 입력 해시·독립 판정·동일 계정/모델/이미지·사전 고정 반복 수를 사용한다. 토큰 계측이 없으면 `unknown`으로 보고하며, 빠른 Flag 발견과 최종 완료 시간을 구분한다.

변경 파일은 `ctf_agent/ctfd.py`, `.github/scripts/check_ctfd_body_remote.py`, `.github/scripts/check_manual_body_remote.py`다. 해당 회귀는 각각 17건과 수동 등록 API 검사에서 통과했고 전체 CI도 통과했다. 2026-11-14 재검사에서 풀이 진행 19건, 로그인 후 격리 14건, 재개 3건, benchmark plan 3건, report 형식 14건이 통과했다. 형식 검사 통과는 정답률 검증이 아니다.
